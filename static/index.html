操作说明

1. 在左侧调整材料和网格参数，点击「应用设置并重置」。

切换薄壳/体积只更新表单，需点击「应用设置并重置」才会重建场景并归零时间。切换保留当前 OBJ 和参数，不自动加载另一套默认值；体积模式要求封闭 OBJ。

「导入 JSON」会立即按文件中的类型、参数和 mesh 路径重建当前会话，无需再点应用。JSON 不包含 OBJ 数据，mesh 必须指向后端项目内已存在的 OBJ；导入不会自动保存到 scene.json。

2. 点击薄片顶点，在右侧输入世界坐标 Fx、Fy、Fz（牛顿），添加多个恒定点力。

3. 点击「开始」或「单步」观察结果；修改、删除力会实时生效。固定点变更会重置几何与速度。

薄壳和体积均调用 Genesis IPC，软体求解在 CUDA 上执行。体积 OBJ 自动四面体化；前端只开放实际表面顶点，可施加点力或固定。薄壳使用原生 Baraff–Witkin，体积使用原生 Stable Neo-Hookean。更新固定点会重建场景。

塑性默认关闭。薄壳的「永久折痕」让超过屈服折角的弯折留下痕迹，不改变拉伸或剪切模型；体积塑性让超过屈服形变的部分留下永久形状，需要项目的原生 CUDA 扩展。硬化越大，之后越难继续留下新变形。应用设置、重置和修改固定点都会清除塑性历史；导出 JSON 只保存参数，不保存变形历史。

坐标系：Z 轴向上。20 cm 薄片总质量约 3.6 g；建议从 0.001 N 点力开始。仿真速度取决于计算耗时，并非固定实时速率。

直接编辑 scene.json / model.obj 后点击「重读文件」。也可从网页替换三角化 OBJ，在网页调整参数后点击「保存到文件」。
